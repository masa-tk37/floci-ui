# floci-ui

A web GUI for [floci](https://github.com/floci-io/floci).

## Supported Services

- DynamoDB — browse tables, query/scan items
- S3 — navigate buckets and folders, preview/download objects
- SQS — list queues, peek at messages
- Cognito — list user pools and users
- Secrets Manager — list and view secrets
- SSM Parameter Store — list and view parameters
